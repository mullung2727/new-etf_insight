## 통합 규칙

- 같은 사건·주제를 여러 영상이 다루면 하나의 하이라이트로 합친다.
- 서로 다른 견해는 합의처럼 만들지 말고 `view_difference`에 남긴다.
- 광고, 잡담, 인사, 채널 홍보, 맥락 없는 반복 뉴스는 제외한다.
- 특정 종목이 없어도 거시·정책·산업·공급망 판단에 가치가 있으면 포함한다.
- 입력 요약에 없는 사실·숫자·고유명사·정책 상태를 추가하지 않는다.
- `evidence`에는 입력에 실제로 나온 수치·계약·실적·공식 발언 등 구체적 근거를 쓴다.
- `investment_links`에는 입력에서 직접 연결되는 종목·산업·테마 이름만 넣는다. 입력에 없는 단어는 쓰지 않는다.
- `source_video_ids`에는 위 입력에 실제 존재하는 `source_ref` 값만 쓴다.
- 확정되지 않은 부분은 `uncertainty`에 한 문장으로 남긴다. 없으면 null.

## 길이 규칙

Discord 메시지에 그대로 들어가므로 아래 분량을 **문장이 끝나는 지점까지** 맞춰 쓴다. 넘기면 잘린다.

- `title` 30자 이내
- `summary` 전체 120자 이내. 서술 문단이 아니라 개조식으로 쓴다 —
  줄바꿈(`\n`)으로 끊은 항목 2~3개, 각 항목 40자 이내.
  - 각 항목은 명사형으로 끝낸다. 예: `HBM 단가 인상으로 하반기 마진 개선`
  - `~이다`, `~한다`, `~되었다` 같은 서술형 종결어미를 쓰지 않는다.
  - 항목 앞에 `-`, `•` 같은 기호를 붙이지 않는다. 줄바꿈만으로 구분한다.
  - 상반된 내용은 한 항목에 몰지 말고 별도 항목으로 나눈다.
- `evidence` 100자 이내
- `view_difference` / `uncertainty` 각 70자 이내
- `investment_links` 항목은 종목·산업 **이름만** 15자 이내(설명 문장 금지)

## 정보가치 점수(100점)

각 하이라이트의 세부 점수를 따로 평가한다.

- `market_impact` 0~25: 업종·지수·공급망·실적에 미치는 범위
- `evidence_quality` 0~25: 숫자·계약·실적·공식 발언 등 근거의 구체성
- `novelty` 0~20: 새 사건·변화인지, 단순 반복인지
- `investment_relevance` 0~20: 실제 투자 판단과 연결되는 정도
- `cross_channel` 0~10: 서로 다른 채널의 영상에서 교차 확인되는 정도(단일 채널이면 0)

높은 점수는 사실 검증 완료나 매수 추천을 뜻하지 않는다. 총점은 코드가 세부 점수 합으로 다시 계산하므로 세부 점수만 정확히 매긴다.

출력은 주어진 JSON 스키마를 정확히 따른다.
