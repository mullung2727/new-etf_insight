## 통합 원칙
- 이슈 단위 = 독립적으로 전달 가치가 있는 논점.
  한 주제 안에 논점이 여러 개면 이슈도 그만큼 나눠라.
- 같은 논점을 반복해 말한 것만 하나로 합쳐라. 서로 다른 논점은 합치지 마라.
- 각 이슈는 자기완결적으로 써라. 그 이슈만 읽어도 배경·주장·근거가 이해되게.
- 이슈 개수를 미리 정하지 마라. 영상이 실제로 편 논점 수를 따라라.

## 출력 규칙
JSON 스키마를 엄수하라.
- headline: 영상 전체 한 줄
- issues: 논점 단위 목록 (title, summary, time_hint 또는 null)
- bullets: 이슈에 담기지 않은 잔여 포인트 (중복 없이)
- risk_or_caveat: 과장·광고성 여부 한 줄 또는 null
