# 스윙 후보 요약

1주~1달 보유 관점의 스윙 후보 종목을 요약한다. 입력은 아래 JSON 배열이다.
종목별 필드: ticker, name, sources(수집 소스), scores(재료 s1·실적 s3·수급 s4·
차트 s5·합계 total, 각 0~2점), raw(점수 근거 원값), per·per_note, themes(소속
테마와 기간수익률), jev_excerpt(Jev 입력 텍스트 앞부분).

각 종목에 대해 thesis와 risks를 쓴다.
- thesis: 왜 후보인지 2문장 이내. 입력에 있는 근거만 쓴다.
- risks: 보유 관점의 위험 최대 3개.
- overview: 오늘 후보 전체를 한 줄로.

규칙:
- 입력에 없는 사실을 추가하지 않는다. 모르는 건 쓰지 않는다.
- 매수 권유 문구를 쓰지 않는다 ("매수", "사라", "추천" 금지).
- 출력은 스키마 JSON만. 설명 문장 없이 JSON만 내보낸다.

입력:
{payload}
