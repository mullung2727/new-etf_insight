위 등록 테마가 원문에 언급됐으면 반드시 결과에 포함하라. 등록 테마와 같은 테마를
새 이름으로 만들지 말고 `match_existing`에 위 이름을 그대로 쓴다.

## 추출 규칙

- 투자 테마(정책·산업·프로젝트 단위, 예 "알래스카 LNG")만 추출한다.
- 막연한 일반론("LNG 시황"), 투자와 무관한 동음어("관광지 알래스카")는 테마가 아니다.
- 개별 종목명 단독 언급은 테마가 아니다.
- 기존 테마 목록의 테마와 같은 테마면 `match_existing`에 목록의 이름을 그대로 쓰고,
  기존에 없는 테마면 `match_existing`을 null로 한다.
- `refs`에는 위 원문에 실제 존재하는 ref만 쓴다. 없는 ref를 만들지 않는다.
- 테마가 하나도 없으면 빈 배열을 반환한다.

출력은 주어진 JSON 스키마를 정확히 따른다.
