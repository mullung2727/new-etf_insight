# 유·무상증자 불기둥 리서치 SPEC

요약: 증자 발표 후 구간별로 "불기둥(하루 +X%)이 나오는가, 언제 나오는가"를 본다. 평균 수익이 아니라 발생 확률과 시점이 목적. 발표 전에 이미 오른 종목은 따로 본다.

"누가 정했나": **사용자** = 사용자가 지정 / **승인** = Claude 제안을 사용자가 승인 / **미승인** = Claude 제안, 확인 필요

## 2. 날짜·구간 정의

- **D0 발표일** = 원문 뷰어 공시 이력 중 `[정정]` 아닌 가장 이른 날짜(`first_announce_date`). 휴장일이면 다음 거래일
  - 공시 시각(장중/장후) 모름 → 발표 직후 구간을 D0~D+1 로 잡아 흡수
- **X 권리락일** = 기준일 직전 거래일
  - 근거: 판타지오 기준일 2024-03-11(월) → 03-08(금) `cmp_prev`로 기준가 165 < 전일종가 200 확인
  - 검증: 재수집 후 X 에서 기준가 < 전일 종가인지 전수 확인, 아니면 그 건 표시(규칙 이탈)
- 구간
  1. **발표 전**: D−20 ~ D−1 (그룹 분리용, 불기둥도 같이 집계)
  2. **발표 직후**: D0 ~ D+1
  3. **발표 ~ 권리락 전**: D+2 ~ X−1 (D+2 > X−1 이면 빈 구간)
  4. **권리락 당일**: X
  5. **권리락 이후**: X+1 ~ X+5
- **유무상은 권리락 2번** (2018~2026 74건 전부 유상 기준일 ≠ 무상 기준일, 보통 1~2달 차) — 사용자 결정 A: 둘 다 따로
  - X1 = 유상 기준일 직전 거래일, X2 = 무상 기준일 직전 거래일
  - 구간 3 은 D+2 ~ X1−1, 구간 4·5 를 X1 에 대해 1번, X2 에 대해 1번 (`권리락당일_유상`, `권리락이후_유상`, `권리락당일_무상`, `권리락이후_무상`)

## 3. 미정

없음.

## 4. 출력

- 구간 × 유형 × 측정(B/C) × 기준(3/5/7/10) 별
  - 발생률: 구간 안에 그 기준 넘은 날이 1번이라도 있는 이벤트 비율
  - 첫 발생 시점 분포 (구간 시작일 기준 몇 번째 거래일)
- 발표 전 상승 그룹별 같은 표
- 출력에 적용값(S6~S11, S13, S14) 한 줄로 찍기

## 5. 알려진 위험

- `guards.jump_ok`(±31%) 는 원래 종가 수익률 기준이면 권리락일 기계적 하락(무상 1:1 → −50%)을 이상치로 잘못 거를 수 있음. 사용 전 코드 확인, 필요 시 기준가 기반 수익률로
- `backtest_daily.adjust.adj_returns` 는 유상 권리락 보정 못 함(주식수 기반 추정). 여러 날 수익률은 `cmp_prev` 기준가로 직접 이어붙임
- KIND 일정 목록의 기준일은 최종(정정 반영) 값. 철회 건 포함 여부 미확인

# 신주 상장 후 물량소화 매수 SPEC (2026-10-02)

| # | 항목 | 값 | 누가 정했나 |
