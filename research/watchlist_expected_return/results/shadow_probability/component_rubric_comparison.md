# 재료강도·선반영·소진 구성점수 테스트

- 기준 시각: D일 15:00 KST
- 최종점수: `clamp(5, 95, 50 + 재료강도 + 신선도 + 독립확인 - 악재 - 선반영 - 소진)`
- 최종점수는 LLM 출력값을 신뢰하지 않고 코드에서 구성점수로 다시 계산한다.
- 과거 15:00 시세 스냅샷과 시각이 없는 기존 근거는 입력에서 제외했다.
- 기존 DB에는 쓰지 않았다.

## 판정

- 구성점수 도입으로 50점 부근 몰림은 완화됐다.
- 강한 재료라도 이미 급등했다면 선반영·소진 감점이 별도로 드러난다.
- 결과 확인 표본 5건에서는 예측력이 개선되지 않았다.
- 도입 전 결과는 15:10 시세와 시각 없는 기존 근거를 포함했으므로 AUC 1.0을 공정한 비교 기준으로 볼 수 없다.
- 15:00 시세 스냅샷이 없는 경우 선반영·소진을 뉴스 제목으로 추정하므로 confidence가 낮고, 운영 검증 전 추가 표본이 필요하다.
