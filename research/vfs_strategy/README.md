# VFS (Volume Flush Spike) 전략 리서치

거래량 폭발 장대양봉 다음의 눌림을 매수하는 신호. 원본은 외부 저장소
`stock_scout/python_scripts/load_krx_data/krx_vfs.py` (pykrx 기반)이고, 여기서는
데이터 소스를 KRX OpenAPI로 바꿔 이식한 뒤 정의를 바꿔가며 측정했다.

데이터·도구 사용법은 [`../BACKTEST_DATA.md`](../BACKTEST_DATA.md).

## 측정 조건

```
비용     왕복 0.6%
분할     신호일 중앙값 기준 전·후반, 둘 다 양수여야 "통과"
일봉     20240801~20260825 (498거래일)
분봉     20250801~ 만 존재 (키움 ka10080 하한). 그 이전은 일봉 근사로 측정
```

## 1. 원본 정의

```
D    거래량 > 20거래일 이동평균 x5,  종가 > 시가 x1.1
D+1  종가 > (D종가 + D시가)/2,  종가 < 시가 x0.99,  거래량 < D거래량 x0.2
```

원본 코드 대조 결과 이동평균은 당일 포함(`rolling(20).mean()`)이 맞고, 다음날은
시장 거래일 인덱스 +1 하나만 본다. 이식본과 일치.

측정 결과:

| 진입 | 표본 | 격자 | 결과 |
|---|---|---|---|
| 신호일 15:19 종가 | 232 | TP 3~7% x SL 1~4% x 보유 1~3일 (60조합) | 전부 음수, 최선 -0.72% |
| 다음날 09:01 | 286 | 무손절 + TP/SL (30조합) | 전부 음수, 최선 -0.49% |
| 다음날 장중 조건부 4종 | 260 | 무손절 + TP/SL (24조합) | 전부 음수 |

## 2. D일 특성 축별 스크리닝 (일봉, 거래량 >= x2 + 눌림 3조건, n=1061)

D일 조건을 축으로 쪼개 밴드별 성과를 측정. 수익률은 D+1 종가 → D+3 종가, 비용 미차감.

**음수 방향이 더 강하게 나온 축:**

```
갭(시가/전일종가) +5~10%       n= 42   -3.75%   t -3.21
눌림강도(D+1거래량/D) <0.05    n= 37   -4.82%   t -3.98
```

**양수 쪽 (전·후반 통과):**

```
거래량배수 7~10        175   +0.48%
몸통(종가/시가) 1.15~1.20   119   +1.35%
종가위치(고가근접) 0.70~0.85  112   +0.27%
눌림강도 0.05~0.10      230   +0.31%
```

전일대비 상승률은 밴드별 단조성도 분할통과도 없었다.

밴드 조합을 분봉으로 확인한 결과:

| 정의 | 분봉표본 | 30조합 결과 |
|---|---|---|
| 제외규칙 + 거래량 7~10 | 149 | 전부 음수 |
| 제외규칙 + 몸통 1.15~1.20 | 110 | 최선 +0.91% (무손절 2일), 분할 실패 |

일봉 +0.73%였던 거래량 7~10 정의가 분봉에서 -0.35%로 어긋난 원인은,
탈락한 14건(15:19에 거래가 없는 저유동성 종목, 평균 +3.58%)이 일봉 수치를 끌어올린 것.

## 4. 2일확인 정의

```

진입 D+3
```

거래정지 가드 적용 효과 (분봉, D+3 09:01 진입, 무손절 1일):

```

```

## 6. 진입 문턱 스윕 — 기간에 따라 방향이 반대

문턱 = 진입일 시가 대비 상승률. 음수 문턱은 `신호일 종가 돌파 즉시 매수`로 수렴한다.
전부 일봉 근사, 무손절 1일 보유.

```
문턱      기존13개월(n=112)   추가과거1년(n=170)   확장25개월(n=282)
-4.0%       +0.72%              +0.15%              +0.39%  O
-2.0%       +0.56%              -0.02%              +0.22%
 0.0%       +0.08%              -0.58%              -0.31%
+2.0%       +1.67%  O           -1.26%              -0.11%
+4.0%       +1.06%  O           -0.95%              -0.06%
```

기존 13개월에서는 문턱 8칸 전부 양수 + 단조 증가 + 전 칸 분할통과였으나,
과거 1년을 추가하자 양수 문턱 구간의 부호가 반대가 됐다(추가 1년은 문턱을 올릴수록 단조 감소).

확장 25개월에서 분할통과는 문턱 -4.0% / -3.0% 두 칸이며 각각 +0.39% (t 0.76),
+0.32% (t 0.64), 승률 39.0%.

## 7. 대칭 TP/SL 승률 (일봉 근사, 확장 25개월)

```
TP/SL     최고 승률     손익분기 승률
 ±1%        29.0%          80.0%
 ±2%        35.7%          65.0%
 ±3%        42.9%          60.0%
 ±5%        44.2%          56.0%
 ±7%        47.0%          54.3%
±10%        44.2%          53.0%
```

진입문턱 3종 x 폭 6종 x 보유 2종 = 36조합에서 승률 60% 이상은 없었고, 최고는 ±7%/보유3일의 47.0%.
순평균은 36조합 전부 음수. 기존 13개월만 보면 `+2% 진입 / ±10% / 1일`이 +0.81% (승률 47.5%)이나
확장하면 -0.70%.

일봉 근사는 같은 날 TP·SL 양쪽 터치를 전부 SL로 처리하므로 승률을 과소평가한다.

## 8. 전 구간에서 반복 확인된 관측

- 손절폭을 좁힐수록 성과가 나빠지고, 무손절(보유 마지막날 종가 청산)이 격자 내 최고인 경우가 대부분
- D+1 장초반(09:01) 매수는 전 모집단에서 음수. 전체 표본 기준 -2.91%, 승률 21.8%, t -15.37
- 거래정지 구간을 걸러내면 성과가 개선됨 (모든 측정에서 같은 방향)
