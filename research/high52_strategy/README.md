# 52주 신고가 전략 리서치

직전 250거래일 고가를 돌파한 종목을 사서 트레일링 스탑으로 파는 신호. 장기투자 관점과
정량(재무) 요소 결합을 목표로 측정했다.

데이터·도구 사용법은 [`../BACKTEST_DATA.md`](../BACKTEST_DATA.md).

> **2026-09 재측정 — §7 최종 정의는 효과 없음.** 일봉을 2022-07 신호부터로 늘리고, 상한가 마감일
> 종가 매수를 체결 불가로 빼자 초과평균 +5.44% (t 4.35) → **+0.35% (t 0.45)**. §1~§9 는 옛 구간
> (신호 20250801~20260226) 기록이고, 현재 결론은 [§10](#10-재측정--긴-데이터--상한가-보정) 부터다.

## 1. 신호 정의

```
당일 고가 > 직전 250거래일 고가          (당일 제외)
가드  룩백 250일 중 실거래 200일 이상
      룩백 구간이 시장 달력상 240일 이상
```

VFS 때 쓰던 `ROWS BETWEEN n PRECEDING` + 완전연속 가드를 250일에 그대로 쓰면 정지 하루만
있어도 종목이 통째로 날아간다(하루 57건 → 2~4건). 장기 룩백은 **시장 거래일 순번(`ms`)
기준 RANGE 윈도우 + 커버리지 하한**으로 가야 한다.

결과: **14,664건 / 1,778종목 / 258거래일** (하루 평균 57건).

```

120거래일 만기        6건 ( 1%)
보유일 중앙 15일
```
120일은 사실상 안 걸리는 상한이다. **장기보유 전략이 아니라 평균 3~4주 트레일링 전략.**

## 5. 폐기된 축 2개 — 둘 다 베타였다

**시가총액 = 사이즈 베타**

```
시총구간 지수 누적:  <1천억 +2.3%  1~3천억 -3.1%  3천~1조 +10.5%  1~5조 +43.9%  5조+ +48.5%

5조+ 신고가   초과(동일가중 전체) +13.37% → 초과(동일시총) +3.06%
승률                       57.3% → 43.0%
```
동일시총 기준으로는 전 구간이 +0.73~+4.65%로 평평하고 초과중앙도 전부 -3.0~-3.7%.

**저변동 베이스(깊이<1.3) = 스팩**

```
깊이<1.3 표본의 거래대금 중앙 2.4억
스팩 비중  이벤트 51/134 (38%), 종목 24/81
  스팩만    초과중앙 +3.81%  승률 74.5%   거래대금 0.1~0.9억 → 매매 불가
  스팩 제외 초과중앙 +1.58%  승률 55.4%
```
스팩은 2,000원 근처에 묶여 이자만큼 우상향해 52주 변동폭이 10% 미만이면서 신고가를 계속
갱신한다. 전체 모집단에선 1.7%뿐인데 저변동 밴드에 몰려 있었다.

## 6. 재무 팩터 — 부채비율만 살아남음

DART 지표 6개를 point-in-time 매칭(`stlm_dt` + 45/90일)해 5분위로 측정. 단독으로는
수익성 지표가 좋아 보였다(ROE Q1 +4.61% vs Q5 +0.51%). 변동성 버킷 안에서 다시 재면:

```
[ROE]   Q1=적자, Q5=고수익
  버킷      버킷평균      Q1        Q5      Q5-Q1
  저변동     +1.32%   +2.41%   +2.36%    -0.05%   ← 차이 소멸
  중변동     +1.78%   +4.40%   -1.84%    -6.24%
  고변동     +2.81%   +5.56%   +0.81%    -4.75%

[부채비율]  Q1=저부채, Q5=고부채(172%+)
  저변동     +1.30%   -0.18%   +7.07%    +7.24%   ← 버킷평균의 5배
  중변동     +1.78%   +1.12%   +6.29%    +5.17%
  고변동     +2.81%   +2.39%   +1.42%    -0.98%
```

ROE는 적자기업이 고변동에 몰린 결과(변동성 대리변수). 부채비율은 저·중변동에서 오히려
더 강해 변동성으로 설명되지 않는다. 업종 베타도 아니다:

```
저·중변동 x 부채Q5      n=350  +6.64%  중앙 +0.20%  승률 50.3%  t 4.53  전반+5.80/후반+7.46
  └ 금융/지주 제외      n=280  +6.35%  중앙 -0.41%  승률 48.2%  t 3.78
  └ 금융/지주만         n= 70  +7.79%  중앙 +4.52%  승률 58.6%  t 2.65
```

부채비율 세분에서 **150%가 경계**, 그 위로 단조 증가:
```
<50%      -0.01%  중앙 -4.49%  승률 37.5%   분할실패
50~100    +0.50%      -5.36%      37.0%   실패
100~150   +0.75%      -3.35%      39.5%   실패
150~200   +2.92%      -0.34%      48.0%   실패
200~300   +6.60%      -2.75%      43.0%   통과
300~500  +10.81%      +0.78%      51.9%   통과
500%+     +5.37%      +1.91%      55.2%   통과
```

성장성(매출·영업이익 증가율 YoY)은 비단조로 방향이 없었고, 이자보상배율은 결측 94.7%로
사용 불가.

## 9. 텔레그램 정성 결합 — 실패 (결론)

과거 백필로 표본을 키운 뒤(51종목 → 865종목) 빈도·정성 두 방향 모두 측정했다. 둘 다 실패.

측정 절차와 함정은 [`../BACKTEST_DATA.md` §4d](../BACKTEST_DATA.md) 에 규약으로 옮겼다.

```
백필      t.me/s 역방향 페이징 7채널 병렬, 85,494건 추가 / 2,797초
          총 108,999건, 결합 표본 51종목 → 865종목
```

**(1) 빈도** — 신호일 이전(D-6~D-1) 언급 건수·채널 수

```
구분              n    초과평균   초과중앙    승률     t     전반     후반  통과
진짜 언급 있음   144   -0.15%   -2.04%  44.4%  -0.13  +1.67%  -1.87%   -
언급 없음        721   +1.65%   -3.11%  39.9%   1.94  +2.85%  +0.51%   O
```
상관 -0.034. 언급 건수 밴드도 비단조(+1.99 / -1.38 / +1.64 / -2.60).

**(2) 정성** — LLM(gpt-5.6-luna) 레이블 블라인드 추출 6필드

```
material_type  실적(72) -1.07% | 테마편승(19) +1.05% | 기타(15) -4.71%
tone           긍정(98) -1.07% | 강한매수(31) +0.52%
specificity    2점(118) -0.16% | 1점(26) -0.13%
is_forward     True(128) -0.93% | False(16) +6.04%
is_recycled    True(78) +0.04% | False(66) -0.37%
```
전 셀 |t| < 1.3, 분할통과 셀 없음. 부호가 일관한 건 `specificity=1 x is_forward=True`
(숫자 없이 기대만 말하는 글) n=19 -3.76% 하나뿐이라 확정 불가.

**원인은 표본이 아니라 분산 부재.** 언급의 실체가 대부분 증권사 리포트 요약이라
specificity=2 가 82%, is_forward=True 가 89%, has_number=True 가 94%다. 변별할 차이가 없다.

**부수 수확 2개** (둘 다 §4d 로):

- `awake_realtimeCheck` 는 봇 채널이고 그 알림이 곧 우리 신호다. 정규식 유형분리는
  53.3% 누수했고, 누수 상태에서는 가짜 단조 패턴이 나온다
- 종목명 문자열 매칭 오탐이 **22.6%** (186 중 42). 이름 길이 필터로 못 잡고
  LLM `is_about_target` 판정이 필요하다

## 10. 재측정 — 긴 데이터 + 상한가 보정

일봉 백필로 신호 구간이 **20220725~20260318** 로 늘었다(여러 장세 포함). 여기에 체결 불가 보정을 더했다.

**상한가 마감일 종가는 살 수 없다.** 매수 주문이 쌓이고 체결되지 않는다. 그런데 이 신호들이
가장 큰 수익을 낸 쪽이라 모든 결과를 부풀리고 있었다.

```
상한가 마감 신호 비율   전체 4.5% | 시총 1천억 미만 14.6% | 3천억+ 2.0%
보정                   backtest.py  신호일 등락률 >= +29% 제외 (LIMIT_UP)
                       near_high_vol.py  다음날 시가 >= 신호일 종가 x 1.29 제외
```

§7 단계표를 긴 데이터 + 보정으로 다시 재면:

```
구분                            n   초과평균   초과중앙   승률     t
① 신고가 전체                6,851   -0.08%   -6.17%  35.5%  -0.26
② + 스팩제외·거래대금10억      6,345   -0.19%   -6.65%  34.5%  -0.58
③ + 베이스깊이 < 2.28        5,276   -0.19%   -6.19%  35.1%  -0.54
④ + 부채비율 >= 150% (최종)     849   +0.35%   -4.56%  38.0%   0.45
```

- 신고가 자체는 사이즈 중립 기준 **초과수익이 없다**
- 부채비율 필터는 옛 구간 한 국면의 산물이었다 (옛 구간 +5.44% → 긴 데이터 +1.40% → 보정 후 +0.35%)
- 소형주가 좋아 보였던 것도 상한가 착시였다. 보정 후 시총 1천억 미만 전체 -1.27% (t -1.68)

## 11. 신고가 근처 거래량 패턴 — 실패

`near_high_vol.py`. 공통: 종가가 직전 250일 고가의 95% 이내(돌파 포함) + 양봉 → 다음날 시가 매수,

서서히  평균 거래량 5>20>60 정배열 + 최근 20일 2배 초과일 없음

- 조건을 풀어 표본을 늘리면 오히려 0 으로 수렴한다

## 12. 저항선 돌파 재정의 — 실패

"신고가 = 저항선 돌파"에 맞게 신호를 엄격하게 재정의했다. 청산은 §7 과 같은 트레일링 -20% / 120일.

```
저항선   직전 250일 고가
나이     그 고가를 처음 찍은 날 이후 경과 거래일
터치     250일 안에서 고가 >= 저항 x 0.97 인 날 (5거래일 이상 떨어져야 새 터치)
```

```
[나이]            n   초과평균     t        [터치 | 나이 60일+]     초과평균
0~19일        4,699   +0.19%   0.49         1회                  -0.55%
20~59일       1,510   +0.75%   1.14         2회                  +0.68%
60~124일        983   +1.38%   1.53         3회                  +1.00%
125일+        2,162   -0.30%  -0.55         4회+                 +0.33%
나이 60+ & 터치 3+  997   +0.62%   0.73
```

- 보정 전에는 "나이 60~124일"이 +2.55% (t 2.72) 로 유력했으나 **상한가 보정 후 소멸**했다
- 많이 막혔던 저항일수록 좋다는 교과서 가설(터치 횟수)은 단조성이 없다
- 연속 신고가(베이스 1~3일)는 보정 전후 모두 가장 약하다

## 13. 검증 방법 교훈

- **전·후반 분할은 검증이 아니다.** 조건을 전 구간을 보고 고른 뒤 두 반쪽을 보는 것이라 둘 다
  in-sample 이고, 과최적화된 조건도 쉽게 통과한다. 여기서 "통과"로 표시된 결과(§4, §7 등)는
  전부 이 한계를 안고 있다
- 대신 **워크포워드**(매년 그 이전 데이터로만 조건을 고르고 다음 해에 적용, 고를 때 몰랐던 결과만
  이어 붙여 평가) 또는 **홀드아웃**(한 시점까지로 고정 → 이후 구간은 바꾸지 않고 검증)을 쓴다
- 10자리 같은 소수 종목 포트폴리오는 신호 하나에도 결과가 크게 흔들린다. 매수 순서를 무작위로
  바꿔 반복한 분포로 운의 폭을 같이 본다
- 체결 가능성(상한가·거래정지)은 성과 필터보다 먼저 확인한다. 이번 연구에서 가장 큰 착시는
  필터가 아니라 체결 가정에서 나왔다
