# 52주 신고가 — 공용 처리 코드

> **이 폴더의 신호 리서치는 전부 기각됐다.** 여기 남은 코드는 다른 리서치·운영 코드가 import 하는
> 공용 처리(분할 보정, 사이즈 중립 지수, 스팩 제외, 상한가 제외) 때문에 유지한다. 지우지 말 것.

데이터·도구 사용법은 [`../BACKTEST_DATA.md`](../BACKTEST_DATA.md).

## 파일

| 파일 | 내용 |
|---|---|
| `backtest.py` | 공용 처리: `_BASE_SQL`, `_ADJ`(분할/병합 보정), `size_neutral_index`, `CAP_EDGES`·`CAP_LABELS`, 상한가 마감 신호 제외 |
| `near_high_vol.py` | `dedup_positions` (보유 중 재신호 제외) |
| `results.json` | 옛 구간 이벤트별 결과 (기록용) |
| `tests/` | unittest |

## 공용 처리 규약

- **분할/병합 보정**: `list_shrs` 비율이 [0.67, 1.5] 밖일 때만 보정한다(작은 변동은 실제 희석).
  신고가 종목은 급등 후 무상증자·액면분할이 잦아 미보정 시 결과가 크게 부풀었다.
- **상한가 마감일 종가는 살 수 없다**: 신호일 등락률 +29% 이상은 체결 불가로 제외한다.
  이 보정 하나로 기존 결론 대부분이 사라졌다.
- **벤치마크**: 같은 시총 구간 동일가중 지수 (사이즈 베타 제거).

## 검증 방법 교훈

- **전·후반 분할은 검증이 아니다.** 전 구간을 보고 고른 조건의 두 반쪽은 둘 다 in-sample 이다.
  워크포워드 또는 홀드아웃을 쓴다.
- 소수 종목 포트폴리오는 신호 하나에도 크게 흔들린다. 매수 순서를 무작위로 바꾼 분포로 운의 폭을 본다.
- 체결 가능성(상한가·거래정지)은 성과 필터보다 먼저 확인한다. 가장 큰 착시는 체결 가정에서 나왔다.
