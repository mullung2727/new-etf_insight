# 52주 신고가 전략 리서치

직전 250거래일 고가를 돌파한 종목을 사서 트레일링 스탑으로 파는 신호. 장기투자 관점과
정량(재무) 요소 결합을 목표로 측정했다.

데이터·도구 사용법은 [`../BACKTEST_DATA.md`](../BACKTEST_DATA.md).

## 측정 조건

```
비용     왕복 0.6%
분할     신호일 중앙값 기준 전·후반, 둘 다 양수여야 "통과"
일봉     20240801~20260825 (498거래일). 52주 룩백에 앞 250일이 소모되어
         신호 가능 구간은 20250801~ (258거래일)
벤치마크  같은 시총 구간 동일가중 지수 (사이즈 베타 제거)
보정     분할/병합 list_shrs, 스팩 제외, DART point-in-time
```

## 1. 신호 정의

```
당일 고가 > 직전 250거래일 고가          (당일 제외)
가드  룩백 250일 중 실거래 200일 이상
      룩백 구간이 시장 달력상 240일 이상
```

VFS 때 쓰던 `ROWS BETWEEN n PRECEDING` + 완전연속 가드를 250일에 그대로 쓰면 정지 하루만
있어도 종목이 통째로 날아간다(하루 57건 → 2~4건). 장기 룩백은 **시장 거래일 순번(`ms`)
기준 RANGE 윈도우 + 커버리지 하한**으로 가야 한다.

결과: **14,664건 / 1,778종목 / 258거래일** (하루 평균 57건).

## 3. 분할/병합 미조정이 결과를 뒤집었다

```
                     보정전      보정후
전종목 120일 평균     +14.16%  →  +10.30%   (중앙값 -0.59%)
  └ 보정대상 3.14%    +145.1%  →   +22.2%
신고가 120일 승률       33.6%  →    45.0%
```

신고가 종목이 급등 후 무상증자·액면분할을 자주 해 **오염이 신호 모집단에 집중**돼 있었다.
`list_shrs` 비율이 [0.67, 1.5] 밖일 때만 보정한다(작은 변동은 실제 희석).

```
스탑           n   초과평균  초과중앙   승률     t     전반    후반  보유일   일당  통과
없음(120일)  3470  +12.60%  -5.41%  43.9%  7.37  +21.59% +3.85%   119  0.106%  O

고점-10%     3470   +1.25%  -2.86%  40.5%  4.32   -0.00% +2.46%    11  0.112%  -
고점-12%     3470   +1.72%  -2.55%  43.0%  5.53   +0.33% +3.07%    14  0.120%  O
고점-15%     3470   +2.29%  -2.30%  44.4%  5.36   +1.32% +3.23%    20  0.113%  O
고점-20%     3470   +4.14%  -2.84%  43.7%  7.45   +4.18% +4.09%    33  0.127%  O
고점-25%     3470   +6.37%  -4.62%  41.6%  7.95   +6.89% +5.86%    47  0.136%  O
```

- 절대 초과수익은 스탑이 넓을수록 크지만, **일당 초과수익은 스탑 쪽이 높다**
- 좁은 스탑(5%, 7%)은 전반이 음수라 분할 실패. 12%가 하한선
- 스탑이 우편향을 줄인다: 초과중앙 -5.41% → -2.30%(15%)
- 최종 채택 **-20%**: 전·후반 +4.18/+4.09로 가장 균질

최종 정의에서 실제 청산 사유:
```
트레일링 -20% 발동  431건 (99%)   평균 보유 24일
120거래일 만기        6건 ( 1%)
보유일 중앙 15일
```
120일은 사실상 안 걸리는 상한이다. **장기보유 전략이 아니라 평균 3~4주 트레일링 전략.**

## 5. 폐기된 축 2개 — 둘 다 베타였다

**시가총액 = 사이즈 베타**

```
시총구간 지수 누적:  <1천억 +2.3%  1~3천억 -3.1%  3천~1조 +10.5%  1~5조 +43.9%  5조+ +48.5%

5조+ 신고가   초과(동일가중 전체) +13.37% → 초과(동일시총) +3.06%
승률                       57.3% → 43.0%
```
동일시총 기준으로는 전 구간이 +0.73~+4.65%로 평평하고 초과중앙도 전부 -3.0~-3.7%.

**저변동 베이스(깊이<1.3) = 스팩**

```
깊이<1.3 표본의 거래대금 중앙 2.4억
스팩 비중  이벤트 51/134 (38%), 종목 24/81
  스팩만    초과중앙 +3.81%  승률 74.5%   거래대금 0.1~0.9억 → 매매 불가
  스팩 제외 초과중앙 +1.58%  승률 55.4%
```
스팩은 2,000원 근처에 묶여 이자만큼 우상향해 52주 변동폭이 10% 미만이면서 신고가를 계속
갱신한다. 전체 모집단에선 1.7%뿐인데 저변동 밴드에 몰려 있었다.

## 6. 재무 팩터 — 부채비율만 살아남음

DART 지표 6개를 point-in-time 매칭(`stlm_dt` + 45/90일)해 5분위로 측정. 단독으로는
수익성 지표가 좋아 보였다(ROE Q1 +4.61% vs Q5 +0.51%). 변동성 버킷 안에서 다시 재면:

```
[ROE]   Q1=적자, Q5=고수익
  버킷      버킷평균      Q1        Q5      Q5-Q1
  저변동     +1.32%   +2.41%   +2.36%    -0.05%   ← 차이 소멸
  중변동     +1.78%   +4.40%   -1.84%    -6.24%
  고변동     +2.81%   +5.56%   +0.81%    -4.75%

[부채비율]  Q1=저부채, Q5=고부채(172%+)
  저변동     +1.30%   -0.18%   +7.07%    +7.24%   ← 버킷평균의 5배
  중변동     +1.78%   +1.12%   +6.29%    +5.17%
  고변동     +2.81%   +2.39%   +1.42%    -0.98%
```

ROE는 적자기업이 고변동에 몰린 결과(변동성 대리변수). 부채비율은 저·중변동에서 오히려
더 강해 변동성으로 설명되지 않는다. 업종 베타도 아니다:

```
저·중변동 x 부채Q5      n=350  +6.64%  중앙 +0.20%  승률 50.3%  t 4.53  전반+5.80/후반+7.46
  └ 금융/지주 제외      n=280  +6.35%  중앙 -0.41%  승률 48.2%  t 3.78
  └ 금융/지주만         n= 70  +7.79%  중앙 +4.52%  승률 58.6%  t 2.65
```

부채비율 세분에서 **150%가 경계**, 그 위로 단조 증가:
```
<50%      -0.01%  중앙 -4.49%  승률 37.5%   분할실패
50~100    +0.50%      -5.36%      37.0%   실패
100~150   +0.75%      -3.35%      39.5%   실패
150~200   +2.92%      -0.34%      48.0%   실패
200~300   +6.60%      -2.75%      43.0%   통과
300~500  +10.81%      +0.78%      51.9%   통과
500%+     +5.37%      +1.91%      55.2%   통과
```

성장성(매출·영업이익 증가율 YoY)은 비단조로 방향이 없었고, 이자보상배율은 결측 94.7%로
사용 불가.

## 7. 최종 정의와 성과

```
신호  당일 고가 > 직전 250거래일 고가 (+ 연속성 가드)
필터  스팩 제외 / 거래대금 >= 10억 / 베이스 깊이 < 2.28 / 부채비율 >= 150%
진입  신호일 종가
청산  고점 대비 -20% 또는 120거래일 만기
```

```
구분                            n   초과평균   초과중앙    승률     t     전반    후반  보유일
① 신고가 전체                3,197   +2.76%   -3.70%  40.9%  4.83  +2.28% +3.22%    28
② + 스팩제외·거래대금10억      2,964   +2.45%   -3.69%  40.8%  4.64  +1.97% +2.93%    26
③ + 베이스깊이 < 2.28        1,999   +2.18%   -3.26%  41.6%  3.72  +1.70% +2.66%    29
④ + 부채비율 >= 150% (최종)     444   +5.44%   -0.27%  48.4%  4.35  +5.08% +5.78%    25
```

기여도는 부채비율이 주력(빼면 +2.18%로 붕괴), 베이스 깊이는 보조.

최종 표본 실체: 종목 198개, 거래대금 중앙 186억, 시총 중앙 3,046억, KOSPI 55%.

## 8. 남은 한계

- **국면 하나.** 신호구간 20250801~20260226, 시장 동일가중 +3.6%. 전·후반이 +5.08/+5.78로

- **초과중앙값 -0.27%.** 0에 붙었을 뿐 양수가 아니다. 승률 48.4% → 개별 종목이 아니라
  **분산 매수 전제**
- 부채비율 150%+ 는 고레버리지. 업종 정규화를 하려 해도 `ohlcv`에 섹터 컬럼이 없다
- 재무 매칭률 96%. DART 지표 API는 2023 사업연도부터만 제공
