# 설정 관리 페이지 — 기획

> **상태**: 구현 완료 (2026-07-08)
> **짝 문서**: 개발 상세는 [settings_admin_tech.md](./settings_admin_tech.md)
> 이 문서는 **화면·기능·흐름·결정**만. 코드/경로는 기술문서로.

## 목적

운영값을 **파일 직접 수정 없이 웹에서** 바꾼다. 지금은 텔레그램 채널만 웹 관리(`/admin/telegram`)되고,
**종가베팅 전략값(매수 기준점수·익손절·예산)은 ps1/py에 하드코딩**돼 있어 바꿀 때마다 파일을 고쳐야 한다
(방금 score_threshold 70→50도 파일 수정이었음).

관리포인트 전수조사 결과:
- 진짜 웹관리감(75점+)은 **종가베팅 전략값 3종**뿐
- 나머지 배치(telegram·naver·krx·financial)는 수집→리포트라 전략 노브 없음
- LLM 모델/프롬프트는 OpenClaw 외부 에이전트 소관 → 이 프로젝트 밖

## 페이지 개편

- `/admin/telegram` → **`/admin/settings`** 로 이름 변경, nav 라벨 "설정"
- 한 페이지 **탭 2개**로 서로 다른 성격의 관리대상을 분리

| 탭 | 관리대상 | UI 성격 |
|---|---|---|
| **텔레그램** | 수집 채널 목록 + 종목탐색 소스(feed_role) | 기존 체크박스 UI 그대로 이식 |
| **종가베팅** | 매수 기준점수 · 익절 · 손절 · 종목수별 예산 | 신규 숫자 폼 + 범위검증 |

## 종가베팅 탭 — 관리 항목 (확정)

| 항목 | 현재값 | 의미 | 입력 형태 | 유효범위 |
|---|---|---|---|---|
| 매수 기준점수 `score_threshold` | 50(테스트)/70 | 이 점수 이상만 매수 후보 | 정수 | 0~100 |
| 익절 `tp` | 0.05 | +5% 도달 시 청산 | **% 입력**(뒤에 `%` 표기) | 0~100 (저장은 소수 0~1) |
| 손절 `sl` | 0.03 | -3% 도달 시 청산 | **% 입력**(뒤에 `%` 표기) | 0~100 (저장은 소수 0~1) |
| 종목수별 예산 `budget` | 1개=300만 / 2개=200만 / 3개=166만 | 매수 종목 수에 따른 종목당 배분 | 정수(원) | 양수 |

## 확정된 결정

- **탭 프레임워크 안 씀**: `useState` 하나로 활성탭 전환. 라우터/탭 라이브러리 금지, 하드코딩 2탭.
- **예산 편집 = 3칸 직접 입력**: 종목수(1/2/3)별 종목당 금액 3칸 각각 입력. 현재 데이터가 종목수마다 총액이 달라(300/400/500만) 총액+분할규칙으로 표현 불가 → 3칸이 데이터와 1:1이라 확정.
- **종가베팅은 raw JSON 편집 금지**: 오타→실주문 로직 크래시 위험. 전용 폼 + 범위검증 필수.
- **dry-run(실주문 on/off)은 웹에서 제외**: 실매수 스위치를 웹 클릭으로 켜면 사고. ps1에 유지.
- **`/admin/json`(cron_registry·별칭 raw 편집)은 그대로 둠**: 성격 다르고 이미 동작. 여기 흡수 안 함.
- **저장 즉시 다음 배치부터 반영**: 배치 py가 실행 시점에 config를 읽음. 실행중 배치엔 영향 없음.
- **비개발 사용자 전제**: 개발 키명(`tp`/`sl`/`score_threshold`) 화면 노출 금지. 필드마다 한글 라벨 + 도움말 1줄 + 단위 접미(`%`/`점`/`원`) 필수. tp/sl은 `%`로 입력·표시(내부 소수 변환). 상세 문구는 tech 필드 UI 카피 표.

## 안전장치

- 값 범위 검증: 클라(입력 즉시) + 서버(저장 직전) + py 로더(로드 후 방어) **3중**.
- 잘못된 값 저장 거부 → 파일 안 건드림. 배치가 깨진 값으로 도는 일 없게.
- 저장 시 직전 버전 백업 1개(`.bak`) — 롤백용.

## 빌드 순서 (단계마다 결과 보고 → 확인 후 다음)

1. 백엔드: `close_bet` config 파일 + 스키마 확정 + py 로더(배치가 읽게) + ps1에서 해당 인자 제거
2. 프론트: `/admin/settings` 셸 + 탭 네비 + 텔레그램 탭 이식
3. 종가베팅 탭: 폼 + 범위검증 + 저장 API
4. nav 라벨/경로 교체, 기존 `/admin/telegram` 정리
