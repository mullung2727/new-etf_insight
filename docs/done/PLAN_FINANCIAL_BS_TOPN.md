# 재무상태표 동적 top-N 행 (회사별 주요 계정 표시)

고정 6행 대신 회사별로 자산 top 5 + 기타, 부채 top 3 + 기타, 총계 3행을 동적 표시. IS·비율 행 유지, UI 섹션 구분.

## 목표 행 구성

```
[재무상태표]
  자산 top 5 (회사별 동적, 예: 유형자산 215조 / 단기금융상품 68조 ...)
  기타자산        = 자산총계 − top5 합
  자산총계
  부채 top 3 (동적)
  기타부채        = 부채총계 − top3 합
  부채총계
  자본총계
[손익계산서]
  매출액 / 영업이익 / 당기순이익      (기존 유지)
[비율]
  영업이익률 / ROE / 부채비율 / 매출증가율 (기존 유지)
```

## 확정 결정 (2026-06-10, 실호출 6개사 검증 후 Q&A)

| 결정 | 내용 |
|---|---|
| top-N 기준 연도 | 최신 연도 금액으로 선정, 행 구성 고정. 과거 연도는 같은 계정 값 표시 |
| 표준 소계 제외 | `CurrentAssets`/`NoncurrentAssets`/`CurrentLiabilities`/`NoncurrentLiabilities`/총계류는 top-N 후보 제외 |
| 비표준 자식 제외 | 표준 항목 직후 ord 연속 + 비표준 코드 + 합계=부모(±0.1%) → 자식 제외, 부모 유지 (삼성생명 보험계약부채 케이스) |
| 동일 계정명 합산 | 같은 account_nm은 1행으로 합산 (현대차 금융업채권 유동+비유동, 기타자산 쌍 등) |
| 잔여 기타 음수 | 보정 없이 그대로 표시 (검증 6개사 중 휴리스틱 적용 후 0건) |
| IS·비율 행 | 유지. UI에서 재무상태표/손익계산서/비율 섹션 구분 |

## 실호출 검증 근거 (`temp/probe-topn-etc.mjs`, 2026-06-10)

- 6개사(삼성전자·신한지주·현대차·카카오·M83·삼성생명) 모두 "연속 ord 구간 = 섹션" 분리 성공
- 표준 소계 제외 후 leaf합 = 총계 정확 일치 (5/6)
- 삼성생명만 부채 이중공시: 보험계약부채(표준, 202.01조) 직후 ord 43~45 비표준 자식 3건 합 202.00조 → 자식 제외 휴리스틱으로 해소
- 상각누계액 등 음수 자산 항목: 6개사 미출현 (DART 표준화 출력은 순액 제공)

## 알고리즘 (lib 순수 함수로 분리)

```
입력: FinancialResponse.list (최신 연도)
1. sj_div="BS" 필터, ord 정렬
2. 연속 ord 구간으로 섹션 분리 (빈 ord 번호 = 경계)
3. 섹션 판별: ifrs-full_Assets 포함 구간 = 자산, ifrs-full_Liabilities 포함 = 부채
4. 표준 소계 제외
5. 비표준 자식 제외 휴리스틱:
   표준 항목 X 직후부터 ord 연속인 비표준 항목들의 합이 X와 ±0.1% 이내면 해당 비표준 항목들 제거
6. 동일 account_nm 합산 → 후보 확정
7. 금액 내림차순 top N 선정
8. 기타 = 총계 − topN 합
출력: { nm, ids[] }[] (행 정의) — ids는 합산된 account_id 집합
```

**과거 연도 매칭:** 행 정의의 `nm` 기준으로 해당 연도 응답에서 동명 항목 합산 (비표준 코드는 id 매칭 불가하므로 nm이 1차 키). 백필 연도(status≠000)는 기존 donor 로직 그대로 — donor 응답에서 nm 매칭 후 frmtrm/bfefrmtrm 추출. 과거 연도 기타 = 해당 연도 총계 − top 행 합 (null 행은 0 취급).

## 추가 — 자본 고정 행 (방안 2, 2026-06-10)

자본은 음수 항목(자본조정·기타포괄손익누계액) 빈발 + 2단 중첩(자본총계 ⊃ 지배주주지분 ⊃ 자본금)
때문에 top-N 부적합 → 표준 고정 행 채택:

```
자본금 / 이익잉여금 / 기타(자본) / 비지배지분 / 자본총계
기타(자본) = 자본총계 − (자본금 + 이익잉여금 + 비지배지분)
```

- 표준 id 3개(`IssuedCapital`/`RetainedEarnings`/`NoncontrollingInterests`) 6개사 fixture 전부 존재 확인
- BS 17행 + IS 3행 + 비율 4행 = 24행, 전체 45/45 통과
- 검토했으나 미채택: 자본 top-N(방안 1, 음수 왜곡), 지배/비지배 2행(방안 3, 정보 부족)
