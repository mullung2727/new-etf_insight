# PLAN — 거래량 Shock–Anchor Breakout 단계별 실험

> **상태: 기각 (2026-10-02).** 핵심 신호(STEP 5) 20일 초과수익 음수·placebo 0, 필터 82칸 생존 0. 홀드아웃 미개봉.
> 결과 기록은 `research/private/volume_shock_anchor/README.md` (비공개).

> 요약: 750일 최고 거래량일 종가(anchor)를 Shock 뒤 **처음** 재돌파한 종목을 t+1 시가에 사는 구조가
> 비용·placebo를 넘는지 14단계로 쪼개 검증한다. 탐색 신호 2023-01-12~2025-12-29, 2026-04~ 는 봉인 홀드아웃.

작성 2026-09-29. 원안(사용자 제공 15단계 계획)을 리뷰해서 확정한 결정만 적는다.

## 1. 기간

```text
사용 데이터 시작   20200102 (DATA_START)
첫 신호 가능      20230112 (750행 이력)
탐색 신호         20230112 ~ 20251229
홀드아웃(봉인)     2026-04-01 ~ 최신
```

- 탐색 신호는 **성과창(최대 60거래일)이 2026-03-31 안에 끝나는 것만** 쓴다 → 마지막 신호 20251229. 성과창이 홀드아웃에 걸치면 봉인 가격을 보는 것이다.
- 홀드아웃 끝에서 미청산 포지션은 마지막 날 종가로 평가하고 `open=True` 로 표시.
- STEP 13 룩백 1250 은 첫 신호가 ≈ 2025-01 이라 표본이 얇다 → 참고용.

STEP 0 실측 (2026-09-29, `results/step0.md`): 탐색 Shock 2,779행 → 기업행위 제외 후 2,015행 · 653일 · 1,099종목.
기업행위 제외 27%, 유상증자·전환 플래그 768건. 제외 후 Shock 의 74% 가 기존 리서치 vr 10+ 구간.

## 3. 통과·기각 기준 (D11)

| 기준 | 값 |
|---|---|
| 표본 | 신호가 나온 **서로 다른 날짜** ≥ 30 |
| 효과 | 날짜별 평균 20일 초과수익 − 0.35% > 0 (5·60일은 참고) |
| Placebo | 같은 날·같은 개수 무작위 종목 1,000회 → 실제가 상위 5% |
| 조건 추가 | 붙이기 전 모델 대비 위 3개 모두 개선. 신호 수만 줄고 성과 동일 = 기각 |

- "전반·후반 둘 다 양수 = 통과" 판정은 쓰지 않는다.
- 특정 종목·월 집중 여부는 상위 5개 종목/월 제거 후 재계산으로 확인(판정 아닌 보고).
