## 1. 데이터 한계 (먼저 알고 시작)

- BRK-B 2010~ 만 → 12개월 신호 2011-02~, 경계 학습 36개월 빼면 평가 ≈ 2014~2026 약 150개월.
- 큰 하락장 2018Q4·2020·2022 세 번뿐 → 레짐 칸당 표본 ~50개월, 3·6개월 미래는 겹쳐서 실효 표본 더 적음.
- 관련 기각: SPY 추세추종(+26.8%/MDD −57%)·듀얼모멘텀(+11.9%/−46%) — `research/private/rejected/REJECTED.md:18`. 과거수익률 단순 타이밍은 이미 졌음 → 이번은 "버크셔 상대강도"가 다른 정보인지가 핵심.

## 2. 계산

1. 월말별 신호 `rel_N = BRK_N개월수익률 − SPY_N개월수익률` (N=3..12).
2. 월말별 레짐 = 그 시점까지 `rel_N` 과거값의 ⅓·⅔ 분위로 상/중/하.
3. 월말별 미래 `fwd_h` = 다음 h개월 SPY 총수익 (h=1,3,6).
4. 칸(N×h = 30칸)마다: 레짐별 평균 `fwd_h`·승률·칸 개수, 상위⅓ − 하위⅓ 차이, 무조건 평균(벤치).
5. t값: 겹침 보정(Newey-West, 지연 h−1).
6. placebo: 신호 시계열을 무작위 원형 이동(1,000회, 레짐 비율·자기상관 유지) → 차이 분위 `validate.placebo_percentile`.
7. 하락 국면 보조표: 레짐별 다음 h개월 SPY 최대낙폭 평균 (방어 국면 가정 확인용).

## 3. 판정 기준 (내 판단, 결과 보기 전 고정)

- **유효**: h=3 또는 6에서 N 10개 중 4개 이상이 placebo 상위 5%(또는 하위 5%), 그리고 10개 N 차이 부호가 전부 같음.
- **단서(LEADS)**: 부호는 일관되나 placebo 통과 N이 1~3개.
- **기각(REJECTED)**: 부호가 N마다 뒤섞이거나 placebo 통과 0개.
- 좋은 N 하나만 골라 "유효" 금지. 전반/후반 분할 검증 안 씀.
