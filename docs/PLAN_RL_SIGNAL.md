## 2. 30초 칸 (P1) — `research/rl_signal/bars.py`

- 칸 경계 09:00:30, 09:01:00, …, 15:19:30 (780칸/일). 각 칸 값 = 경계 시각 직전 마지막 호가 스냅샷 + 지난 30초 체결 집계.
- 수능·새해 첫날 시간 이동: `scripts.market_session.at(date, "09:00:30")` 기준으로 경계를 민다.
- 지표(기준선용, ~15개): 수익률 1·2·10·30칸, 스프레드(호가 단위 수), 1·5호가 잔량 불균형, 30초 체결량(20일 평균 대비), 매수 체결 비율, 장 시작 후 경과 칸, 보유 여부, 평가손익.
- 호가판(CNN용): 시간 20칸 × 호가 20행(매도 10 + 매수 10) × 채널 [잔량, 잔량 증감, 매수 체결량, 매도 체결량] + 스칼라 [보유 여부, 평가손익]. 가격은 호가 단위로 정규화.

## 3. 비용 (P1) — `research/rl_signal/costs.py`

- 스프레드는 체결가(1호가)에 이미 들어감. 여기는 수수료·세금만.
- ETF: 편도 수수료, 거래세 없음. 종목: 편도 수수료 + 매도 거래세.
- 값은 새로 정하지 않는다: P1 첫 작업에서 기존 상수(`research/backtest_daily/stats.py` 의 `COSTS` 내역, broker 수수료 설정)를 grep 해 출처를 이 절에 적는다. 기존 0.35% 는 스프레드 포함 왕복값이라 그대로 쓰면 이중 차감.

## 4. 정답지 (P1) — `research/rl_signal/oracle.py`

- 종목·하루 단위 동적계획법. 상태 = (칸, 보유 여부, 남은 매매 횟수 0~5). 마감 칸에서 거꾸로 계산.
- 매수 체결 = 그 칸 매도1호가, 매도 = 매수1호가, 비용 §3, 15:19:30 강제 청산.
- 출력: 칸별 정답 행동 + 칸별 세 행동의 사후 가치(Q*_hindsight).
- 테스트: 손으로 계산 가능한 5칸 가격열 3개(상승만·하락만·V자)로 정답 행동·총손익 일치, 매매 횟수 5 초과 없음, 비용이 움직임보다 크면 전부 관망.

## 5. 지도학습·전진 검증 (P2) — `research/rl_signal/{baseline,cnn,walkforward}.py`

- 목표: 정답 행동(3분류) 맞히기. 보유 여부를 입력에 넣어 불가능 행동(보유 중 매수 등)은 관망으로 접는다.
- 모델 3개 경쟁, 36종목 한 모델씩:
  - 로지스틱 회귀 (scikit-learn, 가장 단순한 기준선)
  - 그래디언트 부스팅 `sklearn.ensemble.HistGradientBoostingClassifier` (지표 20개 주력 후보, 추가 설치 없음)
  - 작은 CNN (PyTorch CPU, 합성곱 2~3층, 가중치 수만 개)
  - 전진 검증에서 꾸준히 이기는 쪽만 DQN 시작점. 큰 잔차망·MCTS·자기 대국은 안 씀.
- 보조 예측 목표 (KataGo 의 단기 가치 목표 차용): 주 목표 = 정답 행동, 보조 = 30초·5분·15분 뒤 mid 로그수익(종목 변동성으로 나눔). CNN·DQN 은 머리 여러 개로 같이 학습, 부스팅·로지스틱은 주 목표만.
- 지표 확장 (P1 10개 → 20개, `bars.FEATURES` 에 추가):
  - 변동성: 최근 10칸·30칸 실현변동성 (30초 로그수익 제곱합의 제곱근)
  - 하루 단위: 시가(첫 칸 mid) 대비 수익, 당일 고저 사이 위치(0~1, 그 칸까지), 전일 종가 대비 수익
  - 일봉 추세(**전일까지만** — 당일 일봉 조인 금지): 전일 종가의 20일선 이격, 최근 5일 수익, 20일 일봉 변동성. 출처: 종목=KRX 일봉 DB, ETF=`etf_adj_daily.duckdb`
  - 장중 기준선: 당일 VWAP 대비 위치, 30칸 이평 이격
- CNN 입력 = 호가판 + 지표 벡터(가격·모멘텀·변동성은 호가판에 없음). 호가판 추가 채널: 코스피200 ETF(069500) 같은 시점 판, 호가 간격(1호가 대비 bp), 내 진입가 위치.
- 표준화 (`research/rl_signal/scale.py`, 기준선·CNN 공용):
  1. 수익률·변동성 계열 ÷ 그 종목 전일까지 20일 일봉 변동성 (종목 간 크기 맞춤)
  2. 학습 구간만으로 평균·표준편차 → z점수, 평가일엔 그 값 그대로 (평가일 통계 사용 금지)
  3. ±5 에서 자름
  4. 범위가 정해진 값(불균형 −1~1, 매수 비율·경과 0~1)과 호가판은 그대로
- 전진 검증: 거래일 D 밤 = D 까지 학습 → D+1 재생 평가. 평가 = 모델 행동으로 §4 와 같은 체결·비용 규칙 재생한 손익(하루 먼저 평균, 종목 동일가중).
- 기준선 2개: (a) 매 칸 무작위 행동, (b) 모델과 같은 매매 횟수를 그날 무작위 시점에. 각 200회 → 모델 성적의 분위.
- 결과 저장: `research/private/rl_signal/results/YYYYMMDD.json`(일별 성적·분위·매매 수), 모델 `research/private/rl_signal/models/`.

## 6. DQN (P3) — `research/rl_signal/dqn.py`

- 우리 주문이 시세를 안 바꾸므로 매 칸 세 행동의 다음 상태·보상이 모두 정확히 나온다 → 녹화 칸 전체에 세 행동을 다 넣어 학습(탐색 없음, fitted Q 반복).
- 목표값: 보상 + 0.9 × max 다음 칸 Q (보유 여부·남은 매매 횟수 반영), 마감 칸은 강제 청산 보상만.
- 시작 가중치: P2 에서 이긴 쪽(기준선 지표 또는 CNN) 몸통. 평가·기준선은 §5 와 같음.
- 라이브러리: PyTorch 만 (stable-baselines3 불필요 — 온라인 탐색을 안 하므로).

## 10. 판정 규칙 (사전 고정, 2026-11-07)

근거: statistician 리뷰(11-07). 10-20~11-06 결과를 보고 `class_weight` 를 바꿨으므로 그 구간은 **개발 표본**이다.

- **개발 구간**: 2026-11-06 까지. 설계·버그 수정·진단에만 쓰고 합격 판정에 쓰지 않는다.
- **판정 버전 동결**: statistician 지적 수정(아래 "판정 전 수정")을 끝낸 커밋에 태그 `rl-signal-judge-v1`. 확인 구간은 **그 태그 다음 거래일부터**. 이후 지표·모델·하이퍼파라미터·임계값·비용·제외 규칙 중 하나라도 바꾸면 새 태그(v2…)를 달고 확인 구간을 처음부터 다시 센다. 버그 수정도 예외 없음. 판정 버전별 시작일은 아래 표에 기록, judge `--start` 로 그 날짜를 넘긴다.
| 버전 | 태그 커밋 | 확인 시작일 |
|---|---|---|
| v1 | `rl-signal-judge-v1` (PR #158 머지 커밋) | 20261109 |

- **주 모델 1개**: HistGradientBoosting 이득 회귀(정답지 q 의 "매수 이득 = q(BUY)−q(HOLD)", "매도 이득 = q(SELL)−q(HOLD)" 를 회귀, 예측 이득 > 0 일 때만 매매, 조기 종료 끔). 로지스틱·CNN·DQN 은 판정 대상이 아닌 비교·진단.
- **층 분리**: 종목(탑30)과 지수 ETF 6종을 따로 판정. 둘 다 보면 Holm 보정(α 0.05 를 0.025/0.05 로).
- **최소 기간**: 층마다 평가일 60 거래일 이상. (일별 SD 0.3%·효과 +0.1%/일·단측 α 0.05·검정력 0.8 → 약 56일. SD 가 더 크면 늘어남 — 60일 시점 SD 로 필요 일수 다시 계산해 보고하고, 부족하면 판정 연기.)
- **통과 기준 (모두 충족)**:
  1. 일별 순수익(종목 동일가중 하루 평균) 평균의 단측 95% 하한(두 층 모두 볼 땐 Holm) > 0 — 일 블록 부트스트랩.
  2. 라벨 시간 이동 플라시보(같은 종목·날 안에서 정답지 q 를 n/4~3n/4 칸 원형 이동해 라벨·이득을 만들고 같은 상태 표본으로 재학습 → 같은 테스트일 재생) 기간 평균 분포의 95분위 초과.
  3. 보유 경로 순환 이동 플라시보(모델의 보유 구간 길이·횟수 유지, 시작 시점만 무작위) 기간 평균 분포의 95분위 초과.
  4. 확인 구간 총 매매 100건 이상, 1호가보다 한 틱 불리하게 체결해도 건당 순익 +5bp 이상.
- **1차 기준선** = 아무것도 안 함(0%). 장중 보유·균등 무작위·정답지 달성률은 진단 출력으로만.

### 판정 전 수정 (태그 전에 끝낼 것)
- 정답지 달성률·균등 무작위 분위는 진단 전용으로 표시. 플라시보 동률은 ½, 기간 평균 플라시보 분포로 비교.
- 라벨 섞기·보유 경로 순환 이동 플라시보 추가.

- 상·하한가: 종목·하루 제외 대신 칸 단위 거래 불가(매도호가 없으면 매수 불가, 매수호가 없으면 매도 불가, 보유 유지). 제외 이유별 건수 출력.

- 출력: 실제 학습일 수, 매매 수·건당 순익·중앙값·극단일 제외 평균.

- P1 비용 출처 확정: 편도 수수료 0.015%·매도세 0.20% (`research/BACKTEST_DATA.md` 6-1 실측 왕복 0.2306% 분해). ETF 판정은 녹화 6종만 — 탑30 안 다른 ETF 는 종목 비용(보수적)

- 원래 780칸 → 실제 759칸/일 (09:00:30~15:19:30 양끝 포함)
- 원래 호가판 세로 = 현재가 ±10호가 가격격자 → 실제 호가 단계(매도 10~1, 매수 1~10). ETF 호가단위가 종목 호가표와 달라 가격격자 정규화를 피함

- (P2) 보유 중 평가손익 지표 안 넣음 — 보상이 진입가와 무관해 (칸, 보유, 남은 진입) 상태가 마르코프. 대신 [보유, 남은 진입/5] 두 열
