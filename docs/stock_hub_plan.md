# 종목 개괄 허브 — 기획

> **상태**: 기획 확정, 착수 전 (2026-07-07)
> **짝 문서**: 개발 상세는 [stock_hub_tech.md](./stock_hub_tech.md)
> 이 문서는 **화면·기능·흐름·결정**만. 코드/경로는 기술문서로.

## 목적

종목명을 클릭하면 그 종목의 **개괄 허브**로 이동. 네이버금융처럼 탭 하나에서
차트·재무·텔레그램 언급·투자노트를 다 본다. 흩어진 데이터(차트/재무/LLM스코어/
텔레그램/노트/보유손익)를 **종목 단위로 한 곳에** 모으는 게 핵심.

진입 경로: 텔레그램 종목요약(digest) 카드, watchlist, (추후) 종목검색.

## 화면 구성

### 공통 헤더 (탭 위 고정)
- 종목명 · 코드 · 현재가/등락률
- **보유 중이면** 평가손익 배지 (예: `+3.2%`)

### 탭 (URL로 딥링크 — digest에서 바로 특정 탭 열기 가능)

| 탭 | 보이는 것 |
|---|---|
| **개요** | 핵심지표 요약 · LLM스코어 · 최근 텔레그램 언급 3건 · 보유손익 미니 · 최근 노트 1건. 하단에 **이벤트 타임라인**(언급/매매/스코어 변화를 한 날짜축에 겹쳐) |
| **차트** | 캔들차트 + 기간선택(1M/3M/6M/1Y) |
| **재무** | 매출·영업이익·순이익 추이 + ROE/PER 등 지표 |
| **텔레그램** | 이 종목 언급 이력. **기간+세션 필터** · **어느 채널에서 떴는지(소스채널)** · **원문 링크**. 하단에 "같은 테마 언급 종목" 나열+링크 |
| **노트** | 이 종목 투자노트 + 노트 손익 |

## 확정된 결정

- **라우트**: 새 `/stock/[code]` 허브. 기존 `/watchlist/[code]`는 차트 탭으로 리다이렉트.
- **텔레그램 범위 선택**: 기간+세션 필터. 소스채널·원문링크 노출(데이터 있음).
- **투자노트 연동 + 보유손익**: 개요·노트 탭에 표시.
- **이벤트 타임라인**(추가①): 포함.
- **같은 테마 종목**(추가②): **가벼운 버전만** — 나열+링크. 재무 나란히보기는 안 함.
  - *한계*: 종목 테마 출처가 텔레그램 분석뿐 → 텔레그램에 안 뜬 종목은 테마/피어 없음.
- **재언급 알림**(추가③): 기각.

## 빌드 순서 (단계마다 결과 보고 → 확인 후 다음)

1. 종목 메타/현재가 + code→재무매핑 토대
2. 허브 셸 + 탭 라우팅 + 기존 링크 연결
3. 차트 탭
4. 재무 탭
5. 텔레그램 탭 (필터·소스채널·원문)
6. 노트 + 보유손익 탭
7. 개요 탭 + 이벤트 타임라인
8. 같은 테마 위젯

## 미해결 / 나중

- 종목 검색바(임의 종목 진입점) — 진입 경로 초기엔 digest/watchlist로 충분, 필요 시 추가.
- **`+ watchlist 담기` 버튼** (MVP 제외) — watchlist는 KRX 배치가 채우고 쓰기 API가 없다. 수동 담기는 신규 쓰기경로 + 배치 재빌드 시 수동항목 보존 설계 필요. 검색바와 함께 재검토.
- 같은 테마 비교의 재무 나란히보기 — 커버리지 오르면 재검토.
