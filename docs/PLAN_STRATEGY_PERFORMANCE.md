## 1. 현황 (2026-11-20 조사)

  - 되돌림은 `research/private/rl_rebound/results_v3/sup/struct_oos.py` 가 출발점(2026-11-21): 실매매 `signal.precompute` 로 선정 + exp59 `trade()` 로 체결·청산, 원장 대조 표까지 있음. 11-18~20 대조 결과 매수가·목표가 일치, 종가 청산가 1~6원 차이(시장가 vs 15:30 종가).

- 되돌림 원장(`rebound_positions`)은 11-21 분할 매도 반영으로 매도 주문번호가 `sell_ord`·`sell_ord2` 두 열에 나뉨. 체결 수량·손익은 두 열을 합쳐 봐야 함(`realized` 는 그대로 키움 실현손익).
- 기존 `daily-trading-result` 는 옛 종가베팅·눌림용(registry enabled=false) — 재사용 안 함.

## 2. P1 일별 스냅샷
- 새 DB `<데이터루트>/db/performance.sqlite3`, 표 `strategy_daily(date, strategy, kind, seed, flow, flow_note, equity, realized_cum, unrealized, open_n, trades_cum)` — `kind` = `live` | `bt`. `flow` = 그날 시드 변화(원, 미국은 달러), 수익률(TWR) = (equity − flow) / 전날 equity − 1.
- `etl/scripts/strategy_snapshot.py`: 전략별 어댑터 함수 5개가 원장 → (확정 손익, 보유 수량×당일 종가). 종가는 KRX 정규장(`krx_ohlcv`, 키움 종가는 NXT 섞임 주의), 미국은 NY 확정 종가.

## 4. P3 그림자 백테스트
- 전략마다 `kind='bt'` 행을 쓰는 러너: 실매매 시작일~D 를 그 전략 리서치 시뮬레이터로 돌리고 같은 시드로 복리.
- 거래 단위 결과도 `strategy_bt_trades(date, strategy, ticker, entry, exit, ret)` 에 남겨 실매매와 짝짓기.
- 그림자 백테스트는 **날짜별로 그날의 실매매 규칙 버전**을 따른다(현행 규칙으로 과거 전체를 다시 돌리지 않음). 규칙 바뀐 날은 곡선에 표시.
