# PLAN_AFA_REPLICATION

한 줄: Bartram·Grinblatt(2018 JFE) "Agnostic Fundamental Analysis Works" 재현. 매월 시가총액을 회계 항목 전부에 횡단면 회귀(OLS·Theil-Sen)해 "또래 기준 적정가"를 구하고, 괴리율 M=(적정가−시총)/시총 5분위 Q5(저평가)−Q1(고평가) 다음 달 수익을 2010-07~2026-09 미국에서 검증. 논문 표본 끝(2012-12) 이후·게재(2018) 이후에도 남았는지가 핵심.

## 논문 요약 (1987-03~2012-12, 310개월)

- 매월 말 시총 V_j 를 회계 28항목(재무상태표 16 = 최근 분기값, 손익·현금흐름 12 = 최근 4분기 합) + 상수에 횡단면 회귀 → 예측값 P_j
- M = (P−V)/V, 5분위. 표본: 보통주, 주가 ≥$5, 금융(SIC 60~69) 제외, 총자산 >0, 항목 전부 공시
- 항목은 총자산 대비 비율로 상하 5% 윈저(과거 누적 분포)
- Theil-Sen 변형: 100개 기업 무작위 추출 회귀 10만 번 → 기업별 예측값 중앙값
- 결과: EW Q5−Q1 원수익 OLS 0.42%/월 t2.4, TS 0.68% t4.0 / 업종조정 6팩터 알파 OLS 0.62% t5.1, TS 0.87% t8.3 / VW 는 1/4~1/3 약함 / 알파 대부분 Q1(고평가) 숏 쪽 / 34개월에 걸쳐 소멸

## 테스트

- R1 시점: 형성일 뒤 filed 값은 안 쓰임
- R2 TTM: 4분기 합, 분기 3개뿐이면 결측
- R3 OLS: 합성 데이터(V = 2·A + 노이즈)에서 M 부호 = 노이즈 부호 반대
- R4 랭크 부족(완전 공선 항목 2개)에도 예측값 같음
- R5 TS: 이상치 1개 넣으면 OLS 예측은 끌려가고 TS 는 덜 끌려감
- R6 분위: 시총가중 M 합 ≈ 0 (상수항 있는 OLS)
- R7 기존 ccc 테스트 전부 통과
