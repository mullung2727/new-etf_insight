# new-etf-insight SPEC

## 프로젝트 목적

- 한국 신규 ETF 및 상장 예정 ETF 정보를 수집하고 통계로 확인하는 웹사이트를 만든다.
- 주요 데이터 출처 후보는 DART API이며, 필요하면 한국거래소, 운용사 공시, 금융투자협회 등 공개 데이터를 추가로 검토한다.
- 사용자가 신규 ETF 흐름, 운용사별 출시 현황, 기초지수, 자산군, 수수료, 상장일 같은 정보를 빠르게 비교할 수 있게 한다.

## 초기 범위

- 신규 ETF와 상장 예정 ETF 데이터 수집
- 수집 데이터 정규화 및 저장
- ETF 목록, 상세 정보, 기본 통계 대시보드 제공
- 데이터 출처와 갱신 시각 표시

## 제외 범위

- 실시간 매매 기능
- 투자 추천 또는 매수/매도 판단 제공
- 인증 기반 개인화 기능
- 과도한 예측 모델 또는 복잡한 백테스트

## 설계 원칙

- 처음에는 최소 기능으로 시작한다.
- 데이터 수집, 정규화, 표시 계층을 분리한다.
- API 응답 스키마와 데이터 출처 변경 가능성을 버전과 함께 기록한다.
- 코드 수정 전 이 문서를 확인하고, 스펙과 다른 요구가 생기면 먼저 스펙 갱신 여부를 확인한다.

## 버전 주의 사항

- DART API, 프론트엔드 프레임워크, 런타임, 패키지 버전은 작업 시점의 공식 문서 또는 로컬 설정을 확인한 뒤 사용한다.
- 버전 차이로 동작이 달라질 수 있는 코드는 가정하지 않는다.

## 미정 사항

- 기술 스택
- 데이터 저장 방식
- 배포 방식
- DART API 외 추가 데이터 소스
- 통계 지표의 정확한 범위
